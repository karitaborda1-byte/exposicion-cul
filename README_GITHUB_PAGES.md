# El Yo Perdido - Museo Digital 3D

Sitio estatico para publicar en GitHub Pages.

## Estructura

- `index.html`: museo interactivo 3D.
- `assets/`: videos e imagenes usadas por la exposicion.
- `.nojekyll`: evita que GitHub Pages procese o ignore archivos del sitio.

## Importante

Los videos pesan mas de 25 MB. GitHub no permite subirlos desde el navegador web.
Para publicar este sitio completo debes usar GitHub Desktop o Git por linea de comandos.

Despues de subir el repositorio:

1. En GitHub abre `Settings`.
2. Entra a `Pages`.
3. En `Build and deployment`, selecciona `Deploy from a branch`.
4. Elige branch `main` y carpeta `/root`.
5. Guarda.

El sitio quedara en:

`https://TU_USUARIO.github.io/NOMBRE_DEL_REPOSITORIO/`
